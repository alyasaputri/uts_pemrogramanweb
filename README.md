# 📋 Sistem Manajemen Data Mahasiswa

## 1. Deskripsi Sistem
Sistem Manajemen Data Mahasiswa ini merupakan aplikasi berbasis web sederhana yang digunakan untuk mengelola data mahasiswa. Aplikasi ini dibangun menggunakan HTML, CSS, dan JavaScript tanpa menggunakan database, melainkan memanfaatkan Local Storage pada browser untuk menyimpan data.

Sistem ini memungkinkan pengguna untuk menambahkan, mengedit, menghapus, serta mencari data mahasiswa dengan antarmuka yang responsif dan mudah digunakan.

---

## 2. Tujuan
Adapun tujuan dari pembuatan sistem ini adalah:
- Mengimplementasikan dasar pemrograman web (HTML, CSS, JavaScript)
- Memahami penggunaan Local Storage pada browser
- Membuat sistem CRUD (Create, Read, Update, Delete) sederhana
- Menerapkan fitur UI seperti pagination, search, dan dark mode

---

## 3. Fitur Sistem
Sistem ini memiliki beberapa fitur utama, yaitu:
- Input data mahasiswa (NIM, Nama, Jenis Kelamin, Tanggal Lahir)
- Edit dan hapus data mahasiswa
- Pencarian data berdasarkan NIM atau Nama
- Pagination (pembagian data per halaman)
- Mode gelap (Dark Mode) dan mode terang
- Penyimpanan data menggunakan Local Storage

---

## 4. Teknologi yang Digunakan
- HTML (struktur halaman)
- CSS (desain dan tampilan)
- JavaScript (logika dan interaksi pengguna)
- Local Storage (penyimpanan data di browser)

---

## 5. Cara Menjalankan Aplikasi
1. Unduh atau clone repository ini
2. Pastikan semua file berada dalam satu folder
3. Buka file `index.html` menggunakan browser
4. Aplikasi siap digunakan tanpa konfigurasi tambahan

---

## 6. Struktur Program
- `index.html` → Struktur utama aplikasi
- CSS (internal) → Desain tampilan antarmuka
- JavaScript (internal) → Logika CRUD, pagination, search, dan local storage

---

## 7. Kesimpulan
Aplikasi ini merupakan implementasi sederhana dari sistem manajemen data berbasis web yang dapat digunakan untuk memahami konsep dasar CRUD, manipulasi DOM, serta penyimpanan data pada browser menggunakan Local Storage.
